# 🔮 Vedanta Chatbot - Wisdom from the Bhagavad Gita

Vedanta Chatbot is an intelligent assistant powered by deep learning that provides thoughtful answers to users' questions using the teachings of the **Bhagavad Gita**. It suggests relevant **shlokas in Sanskrit** based on the query and helps users find clarity in life through ancient wisdom.

---

## 🧠 How It Works

- Trained on a custom dataset of **Bhagavad Gita questions and shlokas**
- Powered by the **Mistral-7B** transformer model, fine-tuned using Hugging Face
- Accepts user queries and returns relevant Sanskrit shlokas as responses
- Can be used via terminal, UI (planned), or deployed through an API (using FastAPI)

---

## ⚙️ Tech Stack

- 🧠 Model: `Mistral-7B-Instruct-v0.2` (Fine-tuned)
- 🤗 Libraries: `transformers`, `torch`, `bitsandbytes`
- ⚡ API: `FastAPI`, `Uvicorn`
- 🧪 Platform: Developed & tested on `Kaggle`

---

## 🚀 Features

- 🤖 Answers based on **Bhagavad Gita philosophy**
- 🕉️ Shlokas provided in **Sanskrit**
- 💬 Easy-to-use API interface for integration
- 🧘 Terminal interface for spiritual self-inquiry
